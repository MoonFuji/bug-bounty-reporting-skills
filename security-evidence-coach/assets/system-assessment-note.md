# System assessment note (optional)

Use ordinary prose or a small table. This is not a readiness gate.

## Designated system and scope

Revision, supplied material, product promises, permitted operations, and task limit.

## Responsibilities

Principal / object / operation / deciding component / authoritative state / locator.
Separate selected implementation from an unselected example.

## Questions worth resolving

Question, architecture-specific reason, relevant locators, unresolved premise,
and why this question matters relative to the other questions. No numeric score needed.

## What the evidence establishes

Observed facts, derived conclusion, best supported alternative, and scope limit.
Keep a missing artifact distinct from counterevidence.

## Continuation

Settled questions, blocked questions and missing artifacts, remaining scope,
and the next permitted review action. One closed question does not exhaust the system.
