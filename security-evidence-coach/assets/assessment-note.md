# Optional assessment note

Use only what helps the current review. This is not a readiness form.

## Question and scope
Exact proposition, supplied revision, permitted material, and limitations.

## Evidence
Artifact locator | Direct observation | What it does not establish

## Competing explanations
Proposed explanation and best evidence-backed alternative. Which supplied fact
separates them? Name missing evidence rather than guessing.

## Conclusion
Supported / contradicted / inconclusive **for this proposition**.
Brief public rationale, blocking unknowns, and ordinary limitations.
No hidden reasoning transcript, secrets, or unnecessary personal data.

## Resume point
Last decisive artifact; corrected prior belief; unresolved dependency; permitted
next review step. Do not resume from the old verdict alone.
