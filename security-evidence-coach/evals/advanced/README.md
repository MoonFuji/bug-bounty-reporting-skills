# Advanced multi-artifact practice

Twenty-four original fictional packets in eight families: runtime binding,
policy composition, revocation order, retry effects, stratified measurement,
source independence, repair evidence, and relational observation. Each family
contains a supported, contradicted, and inconclusive proposition. The foundational
suite remains unchanged with its original identity and 24 cases.

These are document-snapshot interpretation exercises, not a repository-discovery
benchmark. Each packet has several named evidence artifacts with different roles.
There are no exploit payloads, target endpoints, model API calls, or executable
packet instructions. No performance on an AI model has been measured.

## Commands from the skill directory

```bash
python scripts/practice.py validate --suite advanced
python scripts/practice.py export --suite advanced --output /tmp/security-advanced-inputs
python scripts/practice.py score --suite advanced --answers /path/to/advanced-answers.json
python scripts/test_advanced.py
```

`--suite foundation` is the default and preserves existing commands. Suite IDs
are distinct, and cross-suite answer files are rejected. Run both suites and
retain both results when comparing conditions; do not compare their percentages
as though they measure an identical difficulty or population.

## What makes an answer stronger

A correct label alone earns no claim of expertise. Explain the applicable contract,
the evidence binding it to the operation/revision, the decisive comparison, and
the actual remaining scope limitation. Do not list imaginary uncertainties when
the packet explicitly settles the finite proposition.

The scorer also reports family breakdowns. They expose concentrated errors that
an aggregate hides, but three related packets do not estimate a model's general
ability on an architectural family. Evidence-ID coverage remains a proxy requiring
human entailment review. The evaluator retains the family labels and answer key;
the learner export contains neither.

## Contamination and comparison limits

The [worked lessons](../../references/advanced-worked-lessons.md) and public answer
key teach the same distinctions and reveal conclusions. A run after reading them
is practice or a training condition, not a private held-out evaluation. Provide only
the learner export for packet-only diagnostics, and record all instruction material
available to the assessed model. Avoid exposing alternative packets before a
single-case assessment when that would reveal the contrast structure.

No operation in the tool invokes an AI model. A perfect score using the answer key
is a software arithmetic check, not evidence that a model understood the material.
Use the [human rubric and comparison protocol](../README.md), commission separately
authored private cases before making transfer claims, and retain negative results.
